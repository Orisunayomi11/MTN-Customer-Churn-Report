# MTN-Customer-Churn-Report
Power BI dashboard analyzing customer churn report for MTN Nigeria

Objectives
- Understand customer demographics and behavior — such as age, gender, location, and device usage patterns.
- Measure overall churn rate and identify which customer segments (plans, devices, satisfaction levels) contribute most to churn.
- Examine the relationship between customer tenure, satisfaction rate, and churn likelihood.
- Quantify financial impact by calculating total revenue lost to churn.

Tool Used
- Power BI
- Power Quarey
- GitHub for documentation
